# mcp-servers

MCP servers for [Claude Code](https://claude.ai/code).

## Servers

| Server | Description |
|---|---|
| [simple-task-manager](simple-task-manager/README.md) | Persistent file-based task tracker |

The task manager's skills and full usage rules install as a Claude Code plugin: `/plugin marketplace add dabalroman/mcp-servers`, then `/plugin install tm@dabalroman`.
